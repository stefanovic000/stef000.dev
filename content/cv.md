## Summary

I build websites, apps and the software behind them — mostly in C#, C++ and TypeScript — and I run the servers they live on. One person from the first sketch to the deploy: the page, the program, the TLS, the backups. Most of what I know came from breaking something and having to fix it.

## Experience

**Independent projects** · 2025 — now

- Built and shipped **goodsharing**, a Windows screen-sharing tool on a self-hosted LiveKit SFU: WGC capture, hardware H.264 encoding, end-to-end encryption, Qt Quick UI, and a measurement harness to prove the latency numbers.
- Built **WeAscend**, a quest-based progress system: an append-only XP ledger, ranks and boss quests, and an AI advisor, shipped as a Next.js PWA with an Expo client on a Cloudflare Worker edge API.
- Built **ReverseReverb**, a JUCE audio tool that reverses a sound and shapes the reverb tail leading into it, with a standalone app and a VST3 build.
- Built **node-chat**, a real-time chat on Express and Socket.IO: session-based usernames, server-sanitised messages, image sharing, and a smoke test that covers the socket protocol.
- Run the VPS behind all of it: Linux, systemd, Caddy with automatic TLS, reverse proxies, firewall rules and repeatable deploys over SSH.
- Run the domain's own mail: SPF, DKIM and DMARC configured and verified, so what I send authenticates instead of landing in spam.
- Designed the extraction workflow behind [Extracting Google Earth data](/posts/google-earth-data/): RenderDoc capture → Blender → usable mesh.
